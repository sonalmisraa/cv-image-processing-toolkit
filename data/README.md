# Input data

The sample images in this directory are the images used in the EE604 Image Processing coursework submissions that this project is based on.

- `road_image.png` — road scene for leaf/twig removal
- `rainy_scene.png` — rainy scene for rain-streak removal
- `umbrella.png` — red umbrella image for HSV-based recoloring

For a public GitHub repository, verify that redistribution of course-provided/reference images is permitted. If not, remove these images before publishing and keep the scripts configured to accept user-provided input paths.
